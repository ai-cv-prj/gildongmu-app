수치를 해석하는 방법

관측 수는 OCR 원본 프레임별로 중복을 제거합니다. 같은 인식 결과를 여러 응답에서 재사용한 횟수는 성공 횟수에 더하지 않습니다. ‘번호 채택’은 프로그램이 후보 또는 반복 확인 번호로 채택했다는 뜻이며, 실제 버스 번호와 맞았다는 정답 판정은 아닙니다.

‘결과 나이’는 버스 촬영부터 브라우저 응답 수신까지의 시간입니다. OCR 처리 시간, 대기 시간, 통신 시간이 섞여 있습니다. ‘표시’의 drawn은 캔버스 그리기 완료이며 해당 번호가 실제로 표시됐다는 증거는 아닙니다. stale은 오래된 프레임으로 표시가 생략된 기록입니다. 로그가 없으면 ‘기록 없음’으로 표시합니다.

원본 영상은 연속 촬영이고 분석 영상은 선택된 응답 프레임만 담습니다. 분석 영상은 manifest의 시간 정보로 맞춥니다. 별도 고해상도 OCR 입력은 보관되지 않을 수 있으므로 원본 영상도 당시 OCR에 들어간 JPEG와 정확히 같지는 않습니다.
